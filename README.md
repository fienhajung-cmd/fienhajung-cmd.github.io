# HitungTerbuka

Kalkulator gaji bersih, PPh 21 TER, BPJS, dan THR untuk Indonesia. Situs statis tanpa dependensi.

Situs: https://fienhajung-cmd.github.io/

- Semua angka aturan ada di `assets/hitung.js`.
- Jalankan tes dengan `npm test`.
- Hasilnya perkiraan dan bukan nasihat pajak. Laporkan kesalahan lewat GitHub Issues.
